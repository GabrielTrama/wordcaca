# WordCaça – gerar APK
1. Crie um repositório no GitHub e suba TODO o conteúdo desta pasta (incluindo .github).
2. Aba Actions > "Build APK" > Run workflow (ou só dê push).
3. Ao terminar (~5 min), baixe o artefato "WordCaca-apk" e instale o app-debug.apk no celular.
Para atualizar o jogo: troque www/index.html e dê push.
Para Play Store será preciso um build assinado (.aab) – posso ajudar depois.
